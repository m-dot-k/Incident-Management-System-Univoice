# API UNIvoice

Базовый адрес по умолчанию: `http://127.0.0.1:8000`. Интерактивная документация: `/docs`.

## Авторизация

1. `POST /auth/login` возвращает `access_token`.
2. Во всех остальных запросах передавайте заголовок `Authorization: Bearer <access_token>`.
3. Токен живёт 30 дней. `POST /auth/logout` отзывает его.

Пользователь определяется только по токену. Без токена или с истёкшим токеном сервер отвечает `401`,
при нехватке прав — `403`.

## Эндпоинты

| Метод | Путь | Кто может | Что делает |
|---|---|---|---|
| GET | `/` | все | Проверка, что сервер работает |
| POST | `/auth/register` | все | Регистрация студента |
| POST | `/auth/login` | все | Вход, выдаёт токен |
| POST | `/auth/logout` | с токеном | Выход, отзывает токен |
| GET | `/employees` | администратор | Список активных сотрудников |
| GET | `/incidents` | с токеном | Обращения, доступные пользователю |
| POST | `/incidents` | студент | Создать жалобу или предложение |
| GET | `/incidents/{id}` | с доступом к обращению | Одно обращение |
| POST | `/incidents/{id}/attachments` | автор, статус «Новое» | Добавить фото (поле `file`) |
| GET | `/attachments/{id}` | с доступом к обращению | Фото обращения |
| PATCH | `/incidents/{id}/status` | зависит от статуса, см. ниже | Сменить статус |
| POST | `/incidents/{id}/response` | назначенный сотрудник | Фотоотчёт: `after_photo` обязательно, `before_photo` и `comment` по желанию; статус становится «Решено» |
| GET | `/response-attachments/{id}` | с доступом к обращению | Фото из отчёта сотрудника |
| DELETE | `/incidents/{id}` | автор, статус «Новое» | Отменить своё обращение |
| DELETE | `/admin/incidents/{id}` | администратор | Скрыть обращение, тело: `{"reason": "..."}` (от 5 символов) |

## Кто видит обращения

| Роль | Видит |
|---|---|
| Студент | Только свои обращения |
| Сотрудник | Жалобы, назначенные ему |
| Администратор | Все обращения |

## Смена статуса

`PATCH /incidents/{id}/status` с телом `{"status": "...", "assigned_employee_id": 2, "reason": "..."}`.

| Переход | Кто | Поля |
|---|---|---|
| Новое → Назначено | администратор | `assigned_employee_id` (только для жалоб) |
| Назначено → В работе | назначенный сотрудник | — |
| В работе → Решено | назначенный сотрудник | только через `POST /incidents/{id}/response` |
| Решено → Закрыто | автор обращения | — |
| Решено → Новое | автор обращения | `reason` — что не так; начинается новый круг |

## Фото

- Форматы: JPEG и PNG, тип проверяется по заголовку и по содержимому файла.
- Размер: до 5 МБ каждое, до 5 фото к одному обращению.

## Значения полей

- `type`: `Жалоба` или `Предложение`
- `category`: `оборудование`, `учебный процесс`, `инфраструктура`
- `title`: 5–100 символов; `description`: 20–2000 символов
