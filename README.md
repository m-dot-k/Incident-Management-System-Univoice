# UNIvoice — Incident Management System

**UNIvoice** — мобильное приложение для жалоб и предложений студентов университета.
Студент за минуту отправляет обращение с фото, администратор назначает сотрудника,
сотрудник устраняет проблему и прикладывает фото «после», а студент подтверждает результат.

## Возможности

- Жалобы и предложения по категориям: оборудование, учебный процесс, инфраструктура
- До 5 фото к обращению прямо с камеры или из галереи
- Прозрачные статусы: `Новое → Назначено → В работе → Решено → Закрыто`
- Фотоотчёт сотрудника «до/после» и подтверждение результата студентом
- Возврат на доработку с указанием причины
- Модерация: администратор скрывает неуместные обращения с причиной
- Вход по логину и паролю, сессии на токенах, права ролей проверяются на сервере

## Роли

| Роль | Что может |
|---|---|
| Студент | Создаёт обращения, следит за статусом, принимает результат или возвращает на доработку |
| Сотрудник | Видит назначенные ему жалобы, берёт в работу, публикует фотоотчёт |
| Администратор | Видит все обращения, назначает сотрудников, скрывает обращения |

## Быстрый старт

### 1. Сервер

```bash
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

При первом запуске создаются база и три демо-пользователя: `student`, `employee`, `admin`.
Их пароль сервер печатает в консоль. Чтобы задать свой, укажите переменную `UNIVOICE_DEMO_PASSWORD`.
Документация API в браузере: http://127.0.0.1:8000/docs

### 2. Мобильное приложение

```bash
cd mobile
flutter pub get
flutter run
```

Без настроек приложение обращается к серверу на этом же компьютере: `127.0.0.1:8000` в iOS-симуляторе
и `10.0.2.2:8000` в Android-эмуляторе. Для реального телефона передайте адрес компьютера:

```bash
flutter run --dart-define=API_URL=http://192.168.1.10:8000
```

Подробнее — в [mobile/README.md](mobile/README.md).

## Тесты
