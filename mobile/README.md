# UNIvoice — мобильное приложение

Приложение на Flutter для iOS и Android.

## Запуск

```bash
flutter pub get
flutter run
```

Сервер должен быть запущен (см. [backend/README.md](../backend/README.md)).

### Адрес сервера

| Где запускаете | Команда |
|---|---|
| iOS-симулятор | `flutter run` (адрес `127.0.0.1:8000` подставится сам) |
| Android-эмулятор | `flutter run` (адрес `10.0.2.2:8000` подставится сам) |
| Реальный телефон | `flutter run --dart-define=API_URL=http://<IP компьютера>:8000` |

IP компьютера на macOS: `ipconfig getifaddr en0`. Телефон и компьютер должны быть в одной Wi‑Fi сети.

### iPhone

1. Откройте `ios/Runner.xcworkspace` в Xcode, вкладка **Signing & Capabilities**: выберите свою команду (Team).
2. На iPhone включите **Настройки → Конфиденциальность и безопасность → Режим разработчика**.
3. Запустите `flutter run --release --dart-define=API_URL=...` и при первом запуске подтвердите профиль
   разработчика в **Настройки → Основные → VPN и управление устройством**.

### Android

Debug-сборка (`flutter run`) разрешает обычный HTTP к любому адресу, чтобы работать с локальным сервером.
Release-сборка разрешает HTTP только для `10.0.2.2`, `127.0.0.1` и `localhost` — для рабочего сервера нужен HTTPS.

## Структура `lib/`

| Папка / файл | Что внутри |
|---|---|
| `main.dart` | Точка входа |
| `app.dart` | Корневой виджет `MaterialApp` |
| `config.dart` | Адрес сервера |
| `theme.dart` | Цвета, тема, цвета статусов |
| `models/` | `User`, `Incident` |
| `services/` | `Api` (HTTP-запросы, загрузка фото), вход по логину |
| `screens/` | Экраны: выбор входа, вход, регистрация, главная, лента, обращение, создание, профиль |
| `widgets/` | Переиспользуемые виджеты: статусы, фото, анимации, клавиатура |
| `utils/` | Форматирование дат, проверки полей, помощники интерфейса |
